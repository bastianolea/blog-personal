Lee el script "posts/paisajes/paisajes.R". El objetivo de este script es crear un dataframe con rutas a imágenes y algunos datos sobre cada imagen para construir un mapa interactivo y un post Quarto, similar a "posts/lugares_secretos/index.qmd". A partir de las imágenes en la carpeta "fotos", extraigo las coordenadas GPS de cada imagen desde su EXIF. Con esas coordenadas, quiero extraer el lugar aproximado de cada foto, para darles un título. Por ejemplo, la imagen "paisaje - 1.jpeg", según su EXIF, podría tener asociado el texto "Río Cholqui", "La Unión", "Cerca de Melipilla", o similar. El script tiene que poder obtener estos nombres para cada imagen a partir de sus coordenadas. Los nombres podrían obtenerse desde Open Street Map, y deben referir a la zona de la foto, no a nombres de calles, aunque igual podría ser bueno tener el nombre de la calle como referencia en una variable distinta.
